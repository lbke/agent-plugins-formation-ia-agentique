# Prérequis de la formation LangChain de LBKE

Page officielle de la formation (fait foi) : https://www.lbke.fr/formations/ia/langchain-ia-agentique-python

Résumé relevé sur la page en octobre 2026. Si tu as accès au web, vérifie la page avant de conclure : les prérequis peuvent évoluer.

## Public visé

La formation s'adresse aux développeurs Python de niveau intermédiaire à avancé.

## Prérequis annoncés

- Connaître les bases de la communication client/serveur avec le protocole HTTP.
- Connaître les bases du développement d'applications en Python : bases du langage (fonctions, boucles, conditions), installer et importer une librairie, exécuter un script, utiliser un environnement virtuel.
- Avoir une maîtrise suffisante de l'anglais pour lire des documentations techniques.
- Posséder des comptes gratuits Google Colab, GitHub et Render.com.
- Apporter un ordinateur portable.

## Précisions utiles

- Aucune connaissance préalable en science des données ou concernant les LLM n'est nécessaire.
- Une clé d'accès LLM avec un forfait limité est fournie par LBKE pendant la formation.
- L'environnement de développement est mis en place le premier jour : notebooks sur le cloud avec Google Colab ou installation locale avec `uv`.
- La formation n'est pas une formation à l'utilisation d'assistants IA pour la programmation (voir https://www.lbke.fr/formations/ia/ia-pour-le-code pour ce sujet).
