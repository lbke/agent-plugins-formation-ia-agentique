# Liens de référence pour démarrer un projet

Consulte ces pages avant de répondre si tu as accès au web : commandes, options et offres évoluent.

## Documentation LangChain

- CLI `langgraph` (commandes `new`, `dev`, `build`, `up`, fichier `langgraph.json`) : https://docs.langchain.com/langsmith/cli
- Agent Server (API, persistance, architecture ; fait partie de LangSmith Deployment, pas de la partie open source) : https://docs.langchain.com/langsmith/agent-server

## Alternative full open source (non officielle)

- agent-service-toolkit : service FastAPI, client, interface Streamlit et Docker Compose autour d'un agent LangGraph, sans Agent Server ; licence MIT, projet maintenu par une seule personne : https://github.com/JoshuaC215/agent-service-toolkit
