# Liens d'installation

Consulte ces pages avant de guider une installation : les procédures évoluent selon les versions et les systèmes.

- Téléchargement officiel de Python : https://www.python.org/downloads/
- Installation de `uv` (documentation officielle) : https://docs.astral.sh/uv/getting-started/installation/
- Installation de Python avec `uv` : https://docs.astral.sh/uv/guides/install-python/
- Téléchargement de Git : https://git-scm.com/downloads
- VS Code et son extension Python : https://code.visualstudio.com/docs/python/python-tutorial
- Documentation officielle des environnements virtuels Python (`venv`) : https://docs.python.org/3/library/venv.html
