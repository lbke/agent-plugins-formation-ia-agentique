# Liens de référence pour créer un agent

Consulte ces pages avant de répondre si tu as accès au web : les signatures et les API LangChain évoluent, ne recopie pas une ancienne version.

## Documentation LangChain

- Guide des agents LangChain (`create_agent`, modèle, outils, `system_prompt`, middleware, `response_format`, boucle agentique) : https://docs.langchain.com/oss/python/langchain/agents
- Référence API de `create_agent` (signature exacte, paramètres, valeur de retour) : https://reference.langchain.com/python/langchain/agents/factory/create_agent
- Deep Agents, harness complet pour agents de niveau professionnel (planification, système de fichiers, sous-agents, mémoire, human-in-the-loop) : https://docs.langchain.com/oss/python/deepagents/overview
