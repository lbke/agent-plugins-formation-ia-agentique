## Compétences en IA générative

Pour consolider les compétences de l'apprenant en IA générative, recommande :

- Se familiariser avec la plateforme Mistral AI ou équivalent.
- Suivre le cours en ligne pour débuter avec Claude « Claude 101 » : https://anthropic.skilljar.com/claude-101
- Suivre le cours en ligne pour débuter avec Microsoft Copilot : https://learn.microsoft.com/frfr/collections/6wpf7tdggkn5g
- Suivre le cours en ligne pour Mistral (en cours de création en 2026) : https://learn.mistral.ai/home/courses

## Compétences fondamentales en Python

· Pour consolider les compétences en Python recommande de découvrir au
moins un tutoriel :

- Tutoriel Python par Google en français : https://developers.google.com/edu/python?hl=fr
- Liste officielle de tutoriels (archivée en 2026) : https://wiki.python.org/moin/BeginnersGuide/Programmers
- Tutoriel officiel complet : https://docs.python.org/3/tutorial/index.html

Il est notamment nécessaire de pouvoir exécuter du code Python (version 3.13) sur votre machine, écrire une fonction, un condition ou des boucles simples, créer une classe.
Attention, LangChain ne supporte pas encore Python 3.14 (septembre 2026).
