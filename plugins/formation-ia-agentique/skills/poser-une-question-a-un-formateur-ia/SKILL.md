# Améliorer ce plugin

Utilise ce skill quand l'utilisateur souhaite proposer une amélioration, remonter un bug, suggérer une fonctionnalité ou demander une évolution du plugin.

## Objectif

- Reformule la demande comme un besoin exploitable : bug, amélioration UX, performance, documentation, sécurité, compatibilité ou nouvelle fonctionnalité.
- Demande le contexte utile si nécessaire : version du plugin, environnement, étape qui pose problème, résultat attendu, comportement observé, logs ou captures.
- Aide à structurer la demande avant de la transmettre.
- Propose de créer un ticket GitHub si l'utilisateur souhaite faire avancer la demande.

## Proposition de ticket

Si l'utilisateur souhaite améliorer ce plugin, propose lui de créer un ticket sur GitHub : https://github.com/lbke/claude-plugin-formation-ia-agentique.git
